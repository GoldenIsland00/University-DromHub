# سامانه مدیریت خوابگاه و سلف دانشگاه
# University Dormitory & Cafeteria Management System (Django)

## نصب و اجرا

```bash
# 1. ایجاد محیط مجازی
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

# 2. نصب وابستگی‌ها
pip install -r requirements.txt

# 3. مایگریشن
python manage.py migrate

# 4. داده دمو (اختیاری اما توصیه‌شده)
python manage.py seed_demo

# 5. اجرا
python manage.py runserver
```

سپس به آدرس http://127.0.0.1:8000 بروید.

> ⚠️ اگر از نسخه‌ی قبلی پروژه آپدیت می‌کنید، فایل قدیمی `db.sqlite3` را پاک کنید
> (نسخه قبلی پوشه‌ی migrations نداشت) و دوباره `migrate` و `seed_demo` را اجرا کنید.

## نقش‌ها و پنل‌ها

هر کاربر بعد از ورود، به‌صورت خودکار به پنل مخصوص نقش خودش هدایت می‌شود.

| نقش | آدرس پنل | امکانات |
|-----|----------|---------|
| دانشجو | `/dashboard/` | سفارش غذا (با لغو و بازگشت وجه)، کیف پول، اتاق من، تیکت |
| آشپز | `/panel/cook/` | تعداد سفارش هر غذا (آماده‌سازی)، تحویل غذا به دانشجو، ساخت/ویرایش غذا و قیمت، منوی هفتگی |
| تاسیسات | `/panel/maintenance/` | تیکت‌های خرابی، فیلتر دسته/وضعیت، ارجاع به خود، تغییر وضعیت و پاسخ |
| گارد | `/panel/guard/` | جستجوی دانشجو و ثبت ورود/خروج، لیست افراد بیرون از خوابگاه، گزارش تردد (اگر «بخش» گارد تعیین شود فقط همان بخش را می‌بیند) |
| مدیریت | `/panel/manager/` | آمار کلی، **افزودن/ویرایش/غیرفعال‌سازی کاربر با نقش دلخواه**، تغییر رمز، شارژ کیف پول، دسترسی به همه پنل‌ها |
| مدیر سیستم | همان پنل مدیریت | همه امکانات مدیریت + ساخت مدیر سیستم دیگر و ویرایش مدیران سیستم |

افزودن کاربر جدید: ورود با حساب مدیریت ← منوی «افزودن کاربر» (`/panel/manager/users/new/`).
وارد کردن گروهی دانشجویان از اکسل: `/panel/manager/students/import/` (دانلود نمونه، پر کردن، آپلود).
بک‌آپ و بازگردانی کل داده‌ها: `/panel/manager/backup/` (دانلود SQLite کامل یا JSON + بازگردانی).
کنترل دسترسی در `accounts/permissions.py` (دکوراتورهای `role_required`, `student_required`) انجام می‌شود.

## ساختار اپ‌ها

- **panels**: پنل‌های جداگانه‌ی آشپز، تاسیسات، گارد و مدیریت

- **accounts**: کاربر سفارشی، ثبت‌نام، ورود، پروفایل، نقش‌ها (دانشجو/آشپز/تاسیسات/گارد/مدیریت/مدیر سیستم)، بخش خواهران/برادران
- **dormitory**: ساختمان، اتاق، تخت، اختصاص دانشجو، لاگ ورود/خروج
- **tickets**: تیکت مشکلات اتاق + ارجاع و پاسخ کارکنان
- **cafeteria**: منوی هفتگی، آیتم غذایی، سفارش غذا + کسر از کیف پول
- **wallet**: کیف پول، تراکنش (شارژ / خرید غذا / بازگشت)

## ویژگی‌های حرفه‌ای

- مدل کاربر سفارشی (AbstractUser)
- پشتیبانی کامل i18n (فارسی / انگلیسی) + RTL
- تم دارک / لایت (Frontend)
- سیگنال ساخت خودکار کیف پول
- Context processor برای موجودی و تعداد تیکت‌های باز
- پنل ادمین Django کامل با اینلاین‌ها و اکشن‌ها
- مدیریت تیکت توسط ادمین
- سفارش غذای هفتگی با کسر موجودی
- کد فیش یکتا برای هر وعده + ثبت تحویل توسط آشپز با وارد کردن کد
- جداسازی بخش خواهران و برادران
- وارد کردن گروهی دانشجویان از فایل Excel
- بک‌آپ کامل دیتابیس (SQLite) و خروجی JSON + بازگردانی

## نکات تولید (Production)

- SECRET_KEY را عوض کنید
- DEBUG = False
- ALLOWED_HOSTS را تنظیم کنید
- از PostgreSQL استفاده کنید
- collectstatic و سرو استاتیک با Nginx/WhiteNoise
- درگاه پرداخت واقعی برای شارژ کیف پول

## امکانات جدید (نسخه کامل)

- **اختصاص اتاق/تخت** از پنل مدیریت (`/panel/manager/rooms/`)
- **گزارش و خروجی اکسل**: سفارش غذا، کیف پول، تردد، دانشجویان، اتاق‌ها
- **شارژ آنلاین (درگاه دمو)** با صفحه شبیه‌ساز پرداخت
- **وعده‌های صبحانه / ناهار / شام** با کد فیش جدا برای هر وعده
- **چاپ فیش + QR Code** برای تحویل در سلف
- **اعلان‌های درون‌برنامه‌ای** (موجودی کم، مرخصی، اتاق، شارژ)
- **درخواست مرخصی / خروج شبانه** (دانشجو) + تأیید توسط مدیریت
- **تنظیمات سیستم** (ساعت قطع سفارش، وعده‌های فعال، آستانه موجودی، شارژ آنلاین)
- **محدودیت بخش** برای مدیر غیرسیستم (خواهران/برادران)
- **نمودار نقش‌ها** در داشبورد مدیریت
- **بک‌آپ / بازگردانی** و **وارد کردن دانشجو از اکسل**
